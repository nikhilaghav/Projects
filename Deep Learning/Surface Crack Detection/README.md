Developed an AI-Based Surface Crack Detection System using Convolutional Neural Networks (CNN) to

identify cracks on industrial surfaces from image datasets. Implemented image preprocessing, feature

extraction, and binary classification techniques for accurate defect detection. Trained and evaluated the model

using TensorFlow and Keras with visualization of prediction results and performance metrics.

Tech Stack:

Python, TensorFlow, Keras, OpenCV, NumPy, Matplotlib, Scikit-learn

📌 Project Overview

This project uses Machine Learning to predict whether a passenger survived the Titanic disaster.

The project uses Logistic Regression, a supervised machine learning classification algorithm, to classify passengers into two categories:

0 → Did not survive
1 → Survived

*The complete machine learning workflow is divided into separate functions for:

Loading the dataset

Data preprocessing

Splitting the data

Training the model

Evaluating the model

Preserving the trained model

🎯 Objective

The main objective of this project is to build a Binary Classification Machine Learning Model that predicts Titanic passenger survival based on passenger information.

The project demonstrates an end-to-end Machine Learning workflow:

Dataset

Load Data
   ↓
Data Preprocessing
   ↓
Feature / Target Separation
   ↓
Train-Test Split
   ↓

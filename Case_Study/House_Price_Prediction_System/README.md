📌 Project Overview

This project predicts California housing prices using Bagging Ensemble Learning with a Decision Tree Regressor as the base model.

The project uses the BaggingRegressor algorithm from Scikit-learn to combine multiple Decision Tree Regression models and produce a more stable and accurate prediction.

🎯 Objective

The main objectives of this project are:

1.Load and analyze the California Housing dataset.

2.Separate features and target values.

3.Split the dataset into training and testing sets.

4.Create a Decision Tree Regressor as the base model.

5.Apply Bagging Ensemble Learning.

6.Train the Bagging model.

7.Predict housing prices for test data.

Evaluate the model using:
Mean Squared Error (MSE)
R² Score

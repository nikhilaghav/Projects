*This project demonstrates a Machine Learning classification model using the Decision Tree Classifier.

*The model is trained on the Iris dataset and predicts the species of an Iris flower based on four measurements:

 Sepal Length

 Sepal Width

 Petal Length

 Petal Width

*The model classifies Iris flowers into three species:

 setosa
 
 versicolor
 
 virginica

 *The main objective of this project is to:

1.Load the Iris dataset.

2.Perform Exploratory Data Analysis (EDA).

3.Separate features and target variables.

4.Visualize the dataset.

5.Split the dataset into training and testing sets.

6.Build a Decision Tree classification model.

7.Train the model.

8.Predict the Iris species.

9.Evaluate the model using:
Accuracy
Confusion Matrix
Classification Report

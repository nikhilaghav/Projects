📌 Project Overview

This project predicts whether a customer's loan application will be approved or rejected using Machine Learning classification algorithms.

The project uses three individual classification models:

Logistic Regression

Decision Tree Classifier

K-Nearest Neighbors (KNN)

These models are first trained and evaluated individually.

After that, they are combined using an Ensemble Learning technique called VotingClassifier.

Two types of voting are implemented:

Hard Voting

Soft Voting

The objective is to compare the performance of individual models with ensemble models and understand how combining multiple models can improve prediction performance.

🎯 Objective

The main objectives of this project are:

1.Load and analyze the customer loan dataset.

2.Check for missing values.

3.Separate features and target labels.

4.Split the dataset into training and testing data.

5.Scale the input features.

6.Train Logistic Regression, Decision Tree, and KNN models.

7.Evaluate each individual model.
Create a Hard Voting Classifier.
Create a Soft Voting Classifier.
Compare the accuracy of the different models.

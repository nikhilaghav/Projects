📌 Project Overview

This project predicts product sales based on advertising expenditure across three different advertising channels:

TV

Radio

Newspaper

The project uses Multiple Linear Regression to understand the relationship between advertising expenditure and sales.

The trained model predicts sales and evaluates its performance using MSE, RMSE, and R² Score.

🎯 Objective

The main objectives of this project are:

1.Load the Advertising dataset.

2.Remove unwanted columns if present.

3.Check for missing values.

4.Perform statistical analysis.

5.Analyze correlations between variables.

6.Separate independent and dependent variables.

7.Split the dataset into training and testing data.

8.Train a Multiple Linear Regression model.

9.Predict sales for unseen data.

10.Evaluate the model using regression metrics.
Understand the coefficients learned by the model.

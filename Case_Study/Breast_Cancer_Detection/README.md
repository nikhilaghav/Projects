📌 Project Overview

This project uses Machine Learning to classify breast cancer cases using an Ensemble Learning technique called the Voting Classifier.

The project combines three different Machine Learning algorithms:

Logistic Regression

Decision Tree Classifier

K-Nearest Neighbors (KNN)

These individual models work together through a Voting Classifier to make the final prediction.

The project demonstrates how multiple Machine Learning models can be combined to produce a single prediction.

🎯 Objective

The main objective of this project is to build a classification model that predicts the target class of breast cancer data.
